# MEUS SITES FAVORITOS

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade da Agenda 12 do curso Técnico em Desenvolvimento de Sistemas. Ele consiste na criação de uma página web para apresentar cinco sites favoritos, com imagens, descrições e links de acesso.

## 🎯 Objetivo

O objetivo é colocar em prática os conhecimentos adquiridos sobre HTML e CSS, desenvolvendo uma página web organizada e com links para acessar diferentes sites.

## ⚙️ Funcionamento

A página apresenta cinco cartões, cada um contendo:

- Nome do site;
- Imagem correspondente;
- Pequena descrição;
- Link para acessar o site.

Os links foram configurados para abrir os sites em uma nova aba do navegador.

## 📚 Conteúdos utilizados

- Estrutura básica do HTML5;
- Tags `<title>` e `<h1>`;
- Tags `<h2>`, `<p>` e `<div>`;
- Inserção de imagens com `<img>`;
- Criação de links com `<a>`;
- Atributos `src`, `alt`, `href` e `target`;
- Comentários no código HTML;
- Estilização com CSS;
- Organização de elementos utilizando classes.
